# 🎨 CSS Sandbox

Una colección creciente de mini-proyectos y experimentos de diseño en HTML, CSS y JavaScript. Cada nuevo proyecto que creo se añade aquí para que mis seguidores puedan coger el código, aprender de él y recrearlo.

---

## 📌 Acerca de

Este repositorio es mi sandbox público. Cada carpeta es un proyecto independiente — un diseño de interfaz, animación, experimento de maquetación o una pequeña herramienta — normalmente inspirada o destacada en alguno de mis videos de TikTok. No hay dos proyectos relacionados; piensa en esto como un archivo en funcionamiento más que como una sola aplicación.
